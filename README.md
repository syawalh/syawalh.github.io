# Workout Rumahan

Aplikasi latihan rumahan (PWA) di **https://syawalh.github.io/latihan/**.

- Latihan kekuatan 3× seminggu dengan tangga gerakan tanpa alat khusus, plus kardio bertahap.
- *Pelatih Pintar* menyesuaikan level, set, minggu ringan, dan jalur kardio dari usia, berat, tinggi, kesehatan, alat, dan catatan latihan. Semua aturan berjalan di HP tanpa internet.
- Data tersimpan di perangkat (localStorage). Cadangan bisa diunduh sebagai file `.json`.

Pasang di Android: buka alamat di atas lewat Chrome → menu ⋮ → **Instal aplikasi**.
